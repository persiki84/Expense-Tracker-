# Expense Tracker (Трекер расходов)

**Автор:** Бечелов Алихан Эльдарович

## Описание программы
Программа «Expense Tracker» — это десктопное GUI-приложение для фиксации личных финансов. Приложение позволяет вносить записи о тратах, распределять их по категориям, отслеживать точные даты транзакций, фильтровать историю и автоматически вычислять сумму расходов за выбранный отрезок времени. Данные автоматически сохраняются локально.

## Как использовать
1. **Запуск:** Запустите скрипт командой `python main.py`.
2. **Добавление расхода:**
   - Введите числовое значение в поле «Сумма».
   - Выберите готовую категорию или введите свою.
   - Оставьте текущую дату или укажите другую в формате `ДД.ММ.ГГГГ`.
   - Нажмите кнопку «Добавить расход».
3. **Фильтрация и расчет:**
   - В блоке фильтров выберите нужную категорию и/или укажите временные рамки (поля «С даты», «По дату»).
   - Нажмите кнопку «Применить».
   - Поле «Итого за период» автоматически пересчитает сумму для отфильтрованных строк.
   - Кнопка «Сбросить» возвращает вывод всей истории.

## Тест-кейсы для проверки
* **Тест 1 (Валидация суммы):** Попытка ввода текста "сто" или отрицательного числа "-50" в поле «Сумма» вызовет предупреждение об ошибке.
* **Тест 2 (Валидация даты):** Ввод даты в формате "2026/05/15" вызовет ошибку валидации. Корректный формат: "15.05.2026".
* **Тест 3 (Проверка сохранения):** После закрытия программы все внесенные данные остаются в таблице при повторном запуске благодаря файлу `expenses.json`.
